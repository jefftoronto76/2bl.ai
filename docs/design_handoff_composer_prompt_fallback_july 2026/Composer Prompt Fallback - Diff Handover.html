Composer Prompt fallback + nested Tenant Prompts

Make the fallback state visible, add an explicit revert action, and turn the flat Tenant Prompts list into a collapsible per-tenant tree.

Files
3 — MasterPromptPicker.tsx, page.tsx, TenantPrompts.tsx (all under app/(platform)/platform/settings/)
Shape
~90 lines added, ~15 modified, 0 removed
Surfaces
Platform → Settings only
Risk
Low-medium — new PUT payload shape (promptSetId: null) must be accepted by /api/platform/settings/master-prompt; no other endpoint or data model touched

What changed, in one breath

The Composer Prompt pill now tells you whether production is running a composed prompt set or the code-level default: green pill with set details, or a gray Fallback pill reading "Using system fallback." A new Revert to fallback button (disabled while already on fallback) opens a confirm modal and, on confirm, PUTs { promptSetId: null } — pulling a bad prompt set out of production without requiring a replacement pick first. Separately, Tenant Prompts is now a collapsible tree: one row per tenant (chevron + set count), closed by default, sets indented underneath when expanded; search auto-expands matching tenants. "Add New" stays top-level with its existing Tenant picker.

Behaviour

StatePillRevert button
Composed prompt liveGreen dot · set name · tenant · status badgeEnabled
No pointer set / revertedGray dot · "Using system fallback" · Fallback badgeDisabled

Tenant Prompts: every tenant row starts collapsed. Typing in the search box force-expands any tenant with a match (and collapses back to closed-by-default once the query clears). Creating a set expands and scrolls to its tenant automatically.

API note: confirm PUT /api/platform/settings/master-prompt accepts promptSetId: null as a valid "clear the pointer" payload — the route currently only needs to persist whatever it's given, but this is the first caller sending null intentionally rather than omitting the field.

Verify

  • With no master pointer set, the pill reads "Using system fallback" with a gray Fallback badge; Revert button is disabled.
  • Pick a set in the picker, Save → pill turns green with the set's details; Revert button enables.
  • Click Revert → confirm modal names the current set → confirm → pill returns to the fallback state, picker's pending selection clears.
  • Tenant Prompts: all tenants closed on load; click a row → expands with an indented, left-bordered list; search a set name → its tenant auto-expands, others collapse.
  • Add New (top-level) still requires picking a Tenant first; after saving, that tenant's row expands and scrolls into view.
