What changed, in one breath

Added a GuardrailMeter pill built on the existing Mantine Badge. It counts active guardrail blocks in the current prompt set and recolours by tone: gray at 0–4, yellow at 5, red at 6+ (icon flips to an alert triangle, plus a “reduce to improve reliability” hint). It renders in the summary card and in the collapsed summary bar, and is toggled by a new “Guardrail counter” switch in the Blocks Tweaks panel (on by default). The count recomputes on every render, so it reacts live to enabling/disabling, deleting, or switching sets.
